# WEB-101 — 窄屏任务页布局

原窄屏页头将标题单独居中，创建、范围、刷新和复制操作挤在一起，复制链接
又占一行。现将标题与新建任务同排，范围和工具另排，缩短复制文案，保持完整
无障碍名称。桌面仍使用紧凑单排；移动端工具按钮保留 44px 最小高度。

实际 390×844 预览中，首张任务卡片顶部从 383.34px 提前到 340px，
页头从 133.34px 收至 106px，余下空间来自段间距调整。320px 视口无横向溢出，
范围、刷新和复制仍在同排。1280×720 的桌面双列布局也已目视核对。
