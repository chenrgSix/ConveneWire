application on 2026-09-28. Stable

## Installed owner macOS application

Before replacement, no Runs were active and the old application quit normally.
All 7,316 old application files matched the official v0.5.7 ZIP. A verified
stopped Node snapshot and that matching ZIP remain in the owner's private
application backup directory. The [backup receipt](evidence/qa098/backup-receipt.json)
contains only verification results, not private configuration or work data.

The canonical application was replaced with the verified public v0.5.8 ZIP and
started. All 7,316 installed files match that ZIP. Three identity/configuration
file digests and all five work-table digests match their pre-upgrade baseline:
teams, rooms, messages, runs and agent tasks. SQLite quick_check, liveness and
readiness pass; one desktop process and one bundled Hub process run. See the
[installation receipt](evidence/qa098/installation.json).

Actual installed native navigation passes the workspace toolbar, device panel,
connection/sharing page, Agent settings and return to the local workspace.
This owner profile hosts a Room and has no joined remote space, so the installed
profile's trust toggle was not exercised or changed. Its default/opt-out behavior
is covered by BRG-086 and the exact-source gates above. No LAN configuration,
Agent configuration, sharing permission or real model execution was changed.
The [native UI receipt](evidence/qa098/native-ui.json) records this boundary.

[Cleanup](evidence/qa098/cleanup.json) removed the hidden installation stage,
its old expanded application and 25 temporary download files totaling
545,336,294 bytes. The private rollback ZIP and stopped snapshot remain.
LaunchServices contains one canonical application registration at v0.5.8.
Historical backups were preserved.
