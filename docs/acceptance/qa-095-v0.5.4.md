# QA-095: Publish v0.5.4 and upgrade the local desktop

The owner requested replacement of the local application, cleanup of obsolete
versions and a published release for a subsequent Windows update. This record
records delivery of stable `v0.5.4` after withdrawing the unpublished
`v0.5.3` candidate during actual desktop verification. Delivery state lives only in
[TASKS.md](../TASKS.md).

## Scope And Gates

Use one clean main commit for the immutable tag and all 12 distribution assets.
Pass exact-source Repository, Go, native macOS and native Windows CI before
tagging. Create an empty Draft, run the protected Release workflow and verify
authenticated downloads before publication. Then verify independent anonymous
downloads. Preserve previous releases and tags.

The native Windows gate installs the current stable `v0.5.1`, upgrades to the
candidate and checks payload ownership and retained owner state on uninstall.
This is separate from the owner's later physical Windows update. Codex original
desktop conversation takeover remains macOS-only and experimental.

For the local macOS replacement, retain one compatible old application archive
with a stopped Node snapshot, verify the final version and source, launch the
application and compare retained identity, configuration and work records.
Remove obsolete application archives and stale application registrations only
after the replacement is healthy; preserve private data snapshots. Do not
restart or take over the owner's Codex application or private conversations.
