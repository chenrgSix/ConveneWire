# WEB-100 — 聚焦新建任务

原弹窗一开始就展示所有 Agent 的分工，五位 Agent 会将提交操作推到屏幕之外；
房间信息重复出现，选择控件也偏小。

新布局先展示所属房间、任务名称和目标。Agent 分工默认收起，显示已选人数，
可在创建后安排；交付要求保留为可选区。表单主体独立滚动，底部操作栏保持可见。
角色选择放大，已选 Agent 行突出显示，闭合区域中的控件不进入焦点循环。
房间切换、候选隔离和提交权限保持原有行为。

四个相关测试文件共 18 项通过，覆盖展开与值保留、加载/失败/忙碌状态、焦点循环、
房间切换清空指派及创建请求。生产 TypeScript/Web 构建通过。

本地隔离预览中实测 390×844 和 390×568：展开五位 Agent 后无横向溢出，
短屏底栏位于 y=485.5–555，完整保留在视口内；收起再展开仍保留主负责人，
Escape 关闭后焦点返回新建入口。实际填写名称和目标、不指派 Agent，即可创建并进入任务。
