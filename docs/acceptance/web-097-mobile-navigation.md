# WEB-097 — 窄屏导航不再挤占对话

390 × 844 浏览器实测：旧导航树占用顶部 422 像素，主区域从 y=422 开始，
消息和输入框只能使用剩下的一半高度。

760 像素及以下改为默认关闭的导航抽屉，顶部按钮随时可打开。
选择房间、任务或导航目标后关闭；展开房间树不会误关闭。
使用已有模态组件隔离背景、约束焦点，Escape 或关闭按钮退出并返回触发按钮。
移动端的打开状态与已保存的桌面侧栏偏好独立。

独立审阅发现原模态焦点候选会包含 CSS 隐藏的成员区域和房间选择器，
移动模式现不渲染这两项，并加入包含真实成员 children 的回归。

10 个导航、房间树和关注入口测试通过。实际浏览器验证：
选择默认对话后抽屉关闭，主区域从 y=0 开始；页面宽度等于 390，无水平溢出；
发送一条合成普通消息成功；Escape 后焦点返回“打开导航”。
