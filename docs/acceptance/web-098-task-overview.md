# WEB-098 — 任务概览使用用户语言

本轮实际创建任务后，详情直接显示 `ready`、`normal`、`enabled`、
`owner confirmed` 和 `start work · member`，中文界面还有五个英文页签。
没有设置标准时显示 `0/0`，未开始的任务与缺失上报都用“未知/无”，难以判断含义。

概览现展示本地化的状态、优先级、完成方式、下一步和智能体分工；
下一步显示真实执行人，八个页签均有中文名称。
“尚未设置验收标准”“尚未执行”“尚未提交结果”“未上报”分别表达不同状态。
结果的验收覆盖标为“最新结果中声明满足”，避免将声明误作已独立核验。
完成策略文案也不暗示任务会自动完成。

18 个详情测试通过，最终中文文案的两项回归复跑通过；
与权威合同及 Server RunState 对照，10 类 54 个枚举项均已覆盖。
浏览器实际核对新建任务的房间、状态、页签、负责人和空态。
[浅色任务概览截图](assets/web-095/task-overview-after.png) 留存本轮结果。

页签内部标识、API、命令与权限不变。高级证据、计划和操作记录中的原始诊断
没有在本轮全部翻译；本地浏览器结果不等同于安装版或生产验收。
