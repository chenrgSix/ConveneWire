# ConveneWire v0.5.8

Shared Codex Agents now trust the connected Room service by default, avoiding
repeated permission prompts during cross-device collaboration.

## Per-space execution permissions

Open **设备与协作 → 连接与分享** and find the joined-space card. Its visible
**完全信任此空间** switch defaults to enabled, including existing connections
without a saved preference. Shared Codex can execute commands, read and write
files, and access the network under the local account without per-operation
approval. Turn the switch off to restore the configured restricted sandbox and
local approval prompts. The choice survives restart and reconnect.

Changing the switch stops that connection's current tasks and pending approvals.
Future execution uses a separate native session for the new permission mode;
completed or canceled Runs are not replayed. Agent sharing, Host acceptance,
membership and Room scope still apply. Pi/generic runtimes retain their own
permission behavior, and legacy Device execution trust remains opt-in.

## Cancellation diagnostics

Private local Run diagnostics now retain the first cancellation reason,
approval-wait observations and process cleanup result. A generic canceled status
does not imply that the user canceled it. Diagnostics contain no commands,
credentials or native conversation IDs and are never published to the Room.
Historical cancellations without this evidence cannot be reconstructed.

## Update and rollback

Quit ConveneWire before upgrading and retain a verified stopped Node snapshot
with its matching old application archive. Windows users should install
`convenewire-bridge-desktop_0.5.8_windows_amd64_setup.exe`; Apple-silicon macOS uses
the desktop ZIP. Packages remain unsigned and updates are manual.

There is no new database migration. Saving a per-space execution preference
adds a private state field that older versions cannot read. Do not delete that
field to downgrade: use a compatible version or restore the matching stopped
snapshot and old app together. Existing LAN, manual HTTPS and Relay connection
configuration remains retained.

See [BRG-086 verification](../acceptance/brg-086-peer-execution-trust.md) and
[BRG-085 diagnostics evidence](../acceptance/brg-085-peer-cancellation-diagnostics.md)
for offline checks. Public Relay and physical cross-machine acceptance are
separate; experimental desktop Codex handoff remains macOS-only.
