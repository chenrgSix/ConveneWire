# ConveneWire v0.5.5

This patch fixes the unexpected black console window on Windows desktop startup.
The bundled Local Hub now starts without allocating a Windows console. Local
identity, configuration, work records, startup authentication and graceful
shutdown remain unchanged. No new database migration is included.

## Update

Quit ConveneWire and install
`convenewire-bridge-desktop_0.5.5_windows_amd64_setup.exe`. The portable Windows ZIP
and Apple-silicon macOS ZIP are also available. Keep a verified stopped snapshot
and its matching previous application for rollback. Packages remain unsigned;
Windows requires WebView2. Updates remain manual.

The [v0.5.4 functionality and upgrade boundaries](v0.5.4.md) still apply.
Codex desktop conversation handoff remains experimental and macOS-only.

## Verification

[QA-096](../acceptance/qa-096-windows-hub-window.md) records the native Windows
console-allocation regression, authenticated Hub startup and normal shutdown,
exact-source CI, installer upgrade from v0.5.4 and release-asset verification.
Hosted Windows checks are distinct from the owner's physical-device acceptance.
Public Relay and real-model validation remain outside this patch.
