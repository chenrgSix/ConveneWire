# ConveneWire v0.5.9

Reopening the running desktop from the background preserves the current
conversation, and selecting a conversation opens its latest message. The
workspace's local settings entry is now **配置中心 / Configuration center**.

## Desktop navigation and reading

Ordinary Dock, single-instance and tray activation reveal the current document
without opening the workbench again. This preserves the selected conversation,
draft and reading position while the application is running. Explicit return
from native settings uses a fresh local entry; process exit/restart is a
separate boundary and does not gain saved-page restoration.

Conversation timelines open at the latest message and follow new or resized
content while you remain near the bottom. Scrolling into history stops that
following, and loading older messages preserves the reading anchor.

Windows native settings now return to the local workspace after page reloads
and use the Room's current theme. Configuration center opens the existing
native settings page before and after Runtime binding; connecting a Runtime
to a Team remains an explicit action.

## Peer session continuity and Codex output

When sharing a capable Agent, **恢复同一任务会话** is selected by default and
can be disabled before confirmation. Review and exact retries retain that
choice. Existing shares and Host acceptances are not migrated: to enable
resume on an existing disabled share, explicitly reshare the Agent and have
the Host accept the new version. Ordinary Task runs can then resume their
existing session; Discussion turns continue to use fresh sessions.

The managed Codex protocol reader removes cumulative and individual JSONL
byte ceilings for large tool events. Allocation still depends on individual
event size. Malformed/truncated data fails closed, cancellation interrupts
reads, and visible Room output limits and execution permissions remain intact.

## Update and rollback

Quit ConveneWire before upgrading and keep a verified stopped Node snapshot
with its matching old application archive. Windows users should install
`convenewire-bridge-desktop_0.5.9_windows_amd64_setup.exe`; Apple-silicon macOS
uses the desktop ZIP. Packages remain unsigned and updates are manual.

This release adds no database migration. Existing LAN, HTTPS, Relay and
per-space trust configuration remains retained. If rollback is needed, restore
the compatible stopped snapshot and matching old application together; do not
manually remove private permission or execution state.
