# ConveneWire v0.5.6

LAN collaboration now sets up its secure connection automatically. The workspace
toolbar exposes **设备与协作**, **本机 Agent** and **Codex 会话** directly.
Manual certificate and Relay settings remain under advanced network settings.

## Connect two computers

1. Update both computers, then open **设备与协作** on the computer hosting the Room.
2. Enable LAN, select the Room and copy its connection code.
3. On the other computer, open **设备与协作 → 连接与分享 → 粘贴连接码**.
4. Confirm the displayed Room, then choose which local Agents to share. The Host
   accepts those shares before assigning work.

The app generates and pins its own certificates. No domain, certificate files
or system trust installation is required. Connection codes expire after one
hour; joining is still explicit and Room-scoped by default. Normal restart keeps
the connection identity and trust. Turning LAN off disconnects remote access
while keeping the local workspace open.

Both computers need private IPv4 connectivity. A changed IP address requires a
fresh reviewed code in this version. Nearby auto-discovery and external-browser
access through the managed LAN certificate are not included. Public Relay
acceptance remains deferred.

## Update and rollback

Quit ConveneWire and keep a verified stopped Node snapshot plus its matching old
application before replacing the app. Windows users should install
`convenewire-bridge-desktop_0.5.6_windows_amd64_setup.exe`; Apple-silicon macOS uses
the desktop ZIP. Packages remain unsigned and upgrades are manual.

There is no new database migration. LAN certificates, listener settings and
scoped participant trust are new private installation files. Preserve them with
the rest of the Node snapshot. Existing manual HTTPS/Relay settings remain
readable. An already published origin cannot be silently replaced.

The [v0.5.5 Windows console-window repair](v0.5.5.md) remains included. Experimental
Codex desktop handoff remains macOS-only. [QA-097](../acceptance/qa-097-managed-lan.md)
separates local, CI, release and physical-device evidence.
